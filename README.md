# 🎟️ Event_Booking

A simple event booking system built with Core PHP, MySQL, HTML, CSS, JavaScript (AJAX), and Bootstrap.

---

## Installation

### 1. Import Database
- Open **phpMyAdmin** (or any MySQL client).
- Import the provided `sqlfile.sql` it will created the database.

### 2. Setup Project Files
- Copy the entire project folder into your local server directory:
  - **For XAMPP**: `C:\xampp\htdocs\Event_Booking`
  - **For WAMP**: `C:\wamp\www\Event_Booking`

### 3. Start Server
- Open **XAMPP** or **WAMP** control panel.
- Start **Apache** and **MySQL** services.

### 4. Access the Project
- Open your browser and navigate to:  
  `http://localhost/Event_Booking`

---

## Features

- View list of upcoming events
- Book tickets via AJAX (no page reload)
- Available seats update in real time
- My Bookings table with DataTables support
- Clean UI using Bootstrap
- SweetAlert integration for messages
