⚙️ Installation
Import Database

Open phpMyAdmin (or any MySQL client).
Import the provided sqlfile.sql into a new database (e.g., event_booking).
Setup Project Files
Copy the entire project folder into your local server directory:
For XAMPP: C:\xampp\htdocs\Event_Booking
For WAMP: C:\wamp\www\Event_Booking
Start Server
Run XAMPP or WAMP.
Start Apache and MySQL.
Access the Project
Open your browser and go to:
http://localhost/Event_Booking
